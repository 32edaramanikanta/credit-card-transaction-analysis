# Data Information

## Dataset
This project uses a credit card transaction dataset analyzed in Power BI.

## Analysis Fields
The dashboard contains transaction and customer-related fields including:
- Transaction amount
- Transaction date
- Transaction number
- Category
- Credit card number
- Customer name
- Gender
- Total spend
- Total transactions
- Average transaction value

## Analysis Performed
- Total spending analysis
- Transaction volume analysis
- Average transaction value
- Spending by category
- Monthly spending trends
- Customer/card-level analysis

## Tool
Power BI

> Note: The original dataset file is not included in this repository.
